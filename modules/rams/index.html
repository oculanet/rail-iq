Verification

Method & assumptions

Phase 1 model. Availability is the steady-state inherent availability for service-affecting failures (SAF); non-SAF items count only towards the maintenance failure rate.

Structure

System = subsystems in series. Subsystem = items in series. Item = k-out-of-n identical units in active redundancy, each repaired independently (one repair team per failed unit). Units are assumed independent: no common-cause failure, no standby switching failure, no repair queue.

Formulas

  • Unit: A = MTBF / (MTBF + MTTR), λ = 1 / MTBF.
  • k-out-of-n: A = Σ_{j=k..n} C(n,j) a^j (1−a)^(n−j); failure frequency f = n·a·λ·C(n−1,k−1)·a^(k−1)·(1−a)^(n−k).
  • Series: A = Π A_i, f = A · Σ f_i / A_i (frequency balancing, Billinton & Allan).
  • MTBSAF (mean up time) = A / f; equivalent MTTR (mean down time) = (1 − A) / f; downtime per year = (1 − A) × operating hours × 60 min.
  • Mission reliability: unit R = exp(−t / MTBF) combined through the same structure, without repair.
  • Contribution: improvement potential A_sys(item perfect) − A_sys, shown as a share of the total.

Allocation

  • Equal: A_i = A_T^(1/n), MTBSAF_i = n · MTBSAF_T.
  • ARINC: weights w_i = λ_i / Σλ with λ_i = f_i / A_i from the current design; A_i = A_T^(w_i), MTBSAF_i = MTBSAF_T / w_i.
  • Weighted: as ARINC with the subsystem weights entered in the equipment table.

FMECA

RPN = Severity × Occurrence × Detection, each on 1–10. A failure mode needs action when RPN ≥ the threshold or severity ≥ 9.

Not in Phase 1

Fault trees, Markov models with shared repair or standby, common-cause (β-factor), hazard log and SIL/THR apportionment, logistic delay and spares. Results should be reviewed by a RAM engineer before use in a submission.
