03 / PLATFORM

How Rail-IQ works

A

Runs in the browser

Every simulator is a self-contained web page. Open it from disk, a shared drive or GitHub Pages — nothing to install.

B

Your project data in

Load alignments from Excel and rolling-stock data from Word; every input stays editable and can be exported again.

C

Same engine in Python

Where a model has a Python twin, the browser and command-line versions share one calculation and give the same numbers.

D

Report-ready results

Charts, pass/fail checks and Word, PDF and Excel outputs ready for design submissions.

04 / EXTEND

Add a simulator

Drop the simulator into modules/<id>/ and register it in assets/js/catalog.js. The cards, filters, search, network view and workspace pick it up automatically.

// assets/js/catalog.js { id: "cbtc-headway", title: "CBTC Headway & Capacity", domains: ["metro", "apm"], discipline: "signalling", status: "live", // live | beta | planned entry: "modules/cbtc-headway/index.html", ... }
